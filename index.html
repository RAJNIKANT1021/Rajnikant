01

Full-stack · Generative AI

AI PPT Generation

Type an idea, get a structured, editable PowerPoint deck — with visuals.

PromptHugging Face LLMDeck JSON schemaPreview.pptx

How it works

  1. You describe the deck in a React + Tailwind interface.
  2. A Hugging Face LLM generates the content — as schema-conformant JSON only.
  3. The Unsplash API enriches slides with relevant visuals.
  4. The deck renders as a live preview from the shared schema.
  5. An Express service exports an editable .pptx via PptxGenJS.

Engineering decisions

  • Full-stack monorepo — frontend and export service evolve together.
  • Strict separation: the AI emits only JSON, never markup — output is validated, not trusted.
  • One shared deck schema drives both preview and export, so they never drift apart.
  • Deployed on Render.
